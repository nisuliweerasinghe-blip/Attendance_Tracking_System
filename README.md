
# Real-Time Attendance Tracking System

## Module Details
- Module: EC5205
- Module Name: Operating Systems & Network Programming
- Faculty: Faculty of Engineering, University of Ruhuna

## Project Description
A real-time attendance tracking system that enables lecturers to manage attendance sessions and students to submit attendance through network communication.

## Main Components

### Member 1 – Real-Time Communication
- WebSocket communication using Socket.IO
- Session-based communication rooms
- Live attendance notifications

### Member 2 – Attendance Network Services
- REST API communication
- Attendance submission
- Authentication and authorization

### Member 3 – Network Reliability & Monitoring
- Active connection monitoring
- Heartbeat mechanism
- Disconnection detection
- Reconnection handling
- Missed update synchronization
- Network latency measurement

## Technologies
- Node.js
- Socket.IO
- Express.js
- MongoDB
- React
- Git and GitHub
